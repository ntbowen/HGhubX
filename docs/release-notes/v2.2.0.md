## HGhubX 2.2.0

结构整理 + Android TV 版 + 一轮播放体验改进的正式版本。包含 pre.1 / pre.2 的全部内容与验证。

### 新增

- **Android TV 版**：独立安装包（com.hghubx.tv），Leanback 桌面入口、横屏显示、
  遥控器方向键/确认/返回导航、TV banner 与 overscan 安全边距设置。
- **长按加速可换挡**：右上长按 2x 起，按住左右滑每 80px 换一档（2x → 3x → 4x → 6x，
  来回滑可升可降，每档震动反馈）；上滑后松手锁定当前档位（#146）。
- 设置 → 播放新增「全屏无操作自动隐藏控件」：关 / 3秒 / 5秒 / 10秒（默认 3 秒，
  暂停时不隐藏）（#146）。
- 长按操作提示加入「双击暂停播放」说明（手势本身早已支持）。

### 改进

- **冷启动更快**：已同意协议的用户在启动动画期间就开始选线、加载首屏并请求播放；
  首次使用的协议流程与默认静音不变。
- 加速提示弱化并入顶部倍速胶囊（「上滑后松手锁定 / 松手锁定」），移除画面中部
  误导性的拖放目标提示；全屏右上「退出 / 锁定」两键 44×44、间距 12px（#146）。
- 界面文案清理：设置分组副标题与「清理缓存」行内说明移除（清理范围保留在确认弹窗）；
  「HGhubX 热榜」改名「排行榜」；播放页移除重复的「不感兴趣」按钮，统一长按入口。
- 专题列表卡片去掉可选简介，网格统一高度对齐；专题详情页可展开简介保留。
- 仓库结构整理：前端按 app/features/shared 归组，Rust 按 api/net/media/lines 分模块；
  文档、CI 与尺寸预算随之更新（对使用无感知）。

### 修复

- **切换线路不再掉登录**（#145）：固定线路与发布页确认镜像之间手动/自动切线、重启后
  保留会话；自定义线路仍清空会话，token 不外带。`.ai` 导航站已从线路列表移除。
- **横屏全屏左右滑调进度**（#146）：旋转舞台手势坐标统一换算（进度拖动 / 切集 /
  换挡与锁定）；全屏不再被原生滚动取消手势。
- **全屏控件单击稳定显隐**（#146）：移除不分平台的 2.8s 自动隐藏与单击语义的冲突。
- 竖屏视频在手机上按原始比例完整显示，不再裁切铺满；横屏「铺满 / 适应」保留（#142）。
- 安卓播放诊断日志复制失败：导出裁剪到 256KiB，不再超出剪贴板事务上限（#142）。
- 启动动画期间按返回键不再误触发导航或退出应用。
- TV：「继续观看」封面与货架等宽；选集每格固定高度，长标题两行截断；
  TV 版在跨包迁移后端未移植时也能正常启动。

### 验证

- CI 全绿：Rust 109 通过 / 0 失败，浏览器 smoke 4/4，构建与尺寸预算通过。
- 播放回归 10/10（含 TV 遥控验收 13/13、竖屏适配、恢复与代理切换）。
- 真机手势与 TV 实机显示以安装包实测为准。

### 已知限制

- TV↔手机标准包之间的账号/片库跨包迁移后端尚未移植，TV 端迁移入口保持隐藏。
- iOS 包为无证书构建（需自行签名侧载）；macOS 为 ad-hoc 签名。
